# 🧠 משחק הזכרון

משחק זיכרון (Memory / Concentration) קלאסי עם 4 שלבי התקדמות, בנוי כאפליקציית
Web מתקדמת (PWA) שמותקנת על מסך הבית באנדרואיד ופועלת גם במצב אופליין, בלי
צורך בחנות אפליקציות. אפליקציה עצמאית, ללא קשר לאפליקציות אחרות.

## איך משחקים

- הלוח מוצג עם כל הקלפים הפוכים (גב בלבד).
- לחיצה על קלף הופכת אותו וחושפת את התמונה שעליו.
- לחיצה על קלף שני משווה בין השניים:
  - **זוג זהה** → שני הקלפים נשארים גלויים לצמיתות.
  - **זוג לא זהה** → שני הקלפים הופכים בחזרה לגב אחרי רגע קצר.
- השלב מסתיים רק לאחר שכל הזוגות בלוח זוהו.
- לאחר סיום שלב עוברים אוטומטית לשלב הבא, גדול וקשה יותר.

## שלבי המשחק

| שלב | גודל לוח | מספר קלפים | מספר זוגות |
|-----|----------|-------------|-------------|
| 1   | 2×3      | 6           | 3           |
| 2   | 4×4      | 16          | 8           |
| 3   | 4×6      | 24          | 12          |
| 4   | 6×6      | 36          | 18          |

לאחר השלמת שלב 4 מוצג מסך ניצחון ואפשר להתחיל מחדש משלב 1.

## איך משתמשים (התקנה על אנדרואיד)

1. פתחו את `index.html` (או את הכתובת שבה מתארחת האפליקציה) בדפדפן **Chrome** באנדרואיד.
2. פתחו את התפריט (⋮) ובחרו **"הוספה למסך הבית" / "Add to Home screen"**.
3. האפליקציה תתווסף כאייקון עצמאי שנפתח במסך מלא, כמו אפליקציה רגילה, ותעבוד גם ללא אינטרנט.

להרצה מקומית לצורך פיתוח/בדיקה, כל שרת קבצים סטטי מספיק, לדוגמה:

```bash
python3 -m http.server 8080
# ואז לפתוח http://localhost:8080 בדפדפן
```

## עיצוב

צבעי המשחק: ירוק, תכלת וצהוב — גב הקלף בגרדיאנט תכלת-ירוק, קלף פתוח ברקע צהוב
בהיר, וכפתורי הפעולה בירוק.

## מבנה הפרויקט

```
index.html            מסך האפליקציה (מסך בית עם רשימת שלבים, מסך משחק, מסך תוצאה)
css/style.css         עיצוב, צבעים, אנימציית היפוך קלף
js/memory-data.js      מאגר הסמלים (חיות/צורות) והגדרת 4 השלבים
js/memory-game.js      לוגיקת המשחק: בניית לוח, טיפול בלחיצות, מעקב זוגות, שמירת שיאים
manifest.json          Web App Manifest להתקנה כאפליקציה באנדרואיד
service-worker.js      תמיכה במצב אופליין
icons/                 אייקוני האפליקציה
```

ההתקדמות (שיא מהלכים לכל שלב) נשמרת מקומית במכשיר (localStorage).
