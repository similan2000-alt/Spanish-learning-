# קלפי ספרדית 🇪🇸➜🇮🇱 — לימוד 500 המילים החשובות

אפליקציית קלפים ללימוד 500 המילים הבסיסיות והחשובות בספרדית, עם תרגום לעברית.
בנויה כאפליקציית Web מתקדמת (PWA) שמותקנת על מסך הבית באנדרואיד ופועלת גם
במצב אופליין, בלי צורך בחנות אפליקציות.

## איך משתמשים (התקנה על אנדרואיד)

1. פתחו את `index.html` (או את הכתובת שבה מתארחת האפליקציה) בדפדפן **Chrome** באנדרואיד.
2. פתחו את התפריט (⋮) ובחרו **"הוספה למסך הבית" / "Add to Home screen"**.
3. האפליקציה תתווסף כאייקון עצמאי שנפתח במסך מלא, כמו אפליקציה רגילה, ותעבוד גם ללא אינטרנט.

להרצה מקומית לצורך פיתוח/בדיקה, כל שרת קבצים סטטי מספיק, לדוגמה:

```bash
python3 -m http.server 8080
# ואז לפתוח http://localhost:8080 בדפדפן
```

## איך זה עובד

- **קלף אחד בכל פעם**: מוצגת מילה בספרדית. לחיצה על הקלף הופכת אותו וחושפת את התרגום לעברית.
- **סימון עצמי**: אחרי החשיפה אפשר לסמן **✅ ידעתי** או **❌ טעיתי**.
- **טעיתם?** המילה תחזור להופיע כעבור 2 מילים חדשות אחרות, שוב ושוב, עד שתסומן כ"ידעתי".
- **ידעתם?** המילה תמשיך לחזור באופן אקראי (בין הסשנים) עד שנענתה נכון **5 פעמים בסך הכול** — רק אז היא נחשבת "ידועה" ומופסקת מלהופיע.
- **סשן לימוד = 15 מילים** בכל פעם.
- **קושי עולה בהדרגה**: הסשנים הראשונים מתמקדים במילים הכי חשובות/נפוצות. ככל שמתקדמים ומצליחים יותר, נפתחות מילים נוספות וקשות יותר מתוך רשימת ה-500.
- מסך הבית מציג כמה מילים ידועות לגמרי, כמה בתהליך למידה וכמה נפתחו, וכפתור 📊 פותח מפת התקדמות מלאה על כל 500 המילים.
- ההתקדמות נשמרת מקומית במכשיר (localStorage) — היא נשארת גם אם סוגרים את האפליקציה.

## עיצוב

צבעים בהירים בסגנון תכלת, כחול, צהוב וירוק — צד הספרדית בכרטיס בגוון תכלת-כחול, צד העברית בגוון ירוק-צהוב, וכפתורי הפעולה (ידעתי/טעיתי) בירוק/צהוב בהתאמה.

## משחק מפה עיוורת 🗺️

בנוסף לקלפי הספרדית, האפליקציה כוללת משחק גיאוגרפיה בסגנון "מפה עיוורת": מכפתור **🗺️ משחקי מפה עיוורת** במסך הבית בוחרים קטגוריה —
ערי ישראל, מדינות אירופה, אמריקה הצפונית, אמריקה הלטינית, אסיה או אפריקה — ואז:

- על המפה מודגש אזור אחד (עיר או מדינה), ומוצגת רשימה של עד 10 שמות לבחירה מתוכה.
- תשובה נכונה בניסיון הראשון = 10 נקודות, בניסיון השני = 4 נקודות, מניסיון שלישי ואילך = 2 נקודות.
- כל תשובה נכונה מוסיפה את השם למפה לצמיתות ומוציאה אותו מרשימת השאלות; במקומו נפתח האזור הבא בתור מתוך הרשימה, מהעיר/מדינה הגדולה והמוכרת ביותר ולאט לאט אל הקטנות והפחות מוכרות.
- ההתקדמות והניקוד לכל קטגוריה נשמרים מקומית (localStorage), בדיוק כמו התקדמות הקלפים.
- צורות המדינות מבוססות על נתוני גבולות אמיתיים (ציבוריים). מפת ערי ישראל היא חלוקה גיאומטרית משוערת (Voronoi) סביב מיקום כל עיר בתוך קווי המתאר של ישראל — לא גבולות מוניציפליים רשמיים.

## מבנה הפרויקט

```
index.html            מסך האפליקציה (מסך בית, סשן לימוד, סיום סשן, מודל סטטיסטיקה, מפה עיוורת)
css/style.css         עיצוב, צבעים, אנימציית היפוך קלף, עיצוב משחק המפה
js/words.js           מאגר 500 המילים (ספרדית-עברית, מדורגות לפי חשיבות)
js/app.js             לוגיקת הלמידה: בניית סשנים, מעקב שליטה במילה, שמירת התקדמות
js/mapgame-data.js    נתוני צורות הגבולות (SVG paths) לכל קטגוריה במשחק המפה
js/mapgame.js         לוגיקת משחק המפה העיוורת: קטגוריות, ניקוד, שמירת התקדמות
manifest.json         Web App Manifest להתקנה כאפליקציה באנדרואיד
service-worker.js      תמיכה במצב אופליין
icons/                אייקוני האפליקציה
```

## עטיפה כ-APK אמיתי (אופציונלי)

ה-PWA כבר מתנהג כאפליקציה מלאה במסך הבית. מי שרוצה קובץ APK/פרסום ל-Play Store
יכול לעטוף אותה בקלות עם כלים כמו [PWABuilder](https://www.pwabuilder.com/) או
Trusted Web Activity (TWA) של Google, בלי לשנות קוד — כי הקובץ `manifest.json`
כבר כולל את כל הנדרש (שם, אייקונים, צבעים, מצב standalone).
