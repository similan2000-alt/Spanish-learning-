# קלפי ספרדית 🇪🇸➜🇮🇱 + מפה עיוורת 🗺️

הריפו הזה מכיל **שתי אפליקציות עצמאיות ונפרדות** (כל אחת עם ה-`index.html`, ה-manifest וה-service worker משלה — אין ביניהן כפתור או קישור הדדי):

- **`/` (שורש)** — קלפי ספרדית: אפליקציית קלפים ללימוד 500 המילים הבסיסיות והחשובות בספרדית, עם תרגום לעברית.
- **`/map-game/`** — מפה עיוורת: משחק גיאוגרפיה נפרד לזיהוי ערי ישראל ומדינות ביבשות שונות.

שתיהן בנויות כאפליקציות Web מתקדמות (PWA) שמותקנות על מסך הבית ופועלות גם במצב אופליין, בלי צורך בחנות אפליקציות. פרטים על כל אחת בהמשך.

## קלפי ספרדית

אפליקציית קלפים ללימוד 500 המילים הבסיסיות והחשובות בספרדית, עם תרגום לעברית.

## איך משתמשים (התקנה על אנדרואיד)

1. פתחו את `index.html` (או את הכתובת שבה מתארחת האפליקציה) בדפדפן **Chrome** באנדרואיד.
2. פתחו את התפריט (⋮) ובחרו **"הוספה למסך הבית" / "Add to Home screen"**.
3. האפליקציה תתווסף כאייקון עצמאי שנפתח במסך מלא, כמו אפליקציה רגילה, ותעבוד גם ללא אינטרנט.

להרצה מקומית לצורך פיתוח/בדיקה, כל שרת קבצים סטטי מספיק, לדוגמה:

```bash
python3 -m http.server 8080
# ואז לפתוח http://localhost:8080 בדפדפן
```

## איך זה עובד

- **קלף אחד בכל פעם**: מוצגת מילה בספרדית. לחיצה על הקלף הופכת אותו וחושפת את התרגום לעברית.
- **סימון עצמי**: אחרי החשיפה אפשר לסמן **✅ ידעתי** או **❌ טעיתי**.
- **טעיתם?** המילה תחזור להופיע כעבור 2 מילים חדשות אחרות, שוב ושוב, עד שתסומן כ"ידעתי".
- **ידעתם?** המילה תמשיך לחזור באופן אקראי (בין הסשנים) עד שנענתה נכון **5 פעמים בסך הכול** — רק אז היא נחשבת "ידועה" ומופסקת מלהופיע.
- **סשן לימוד = 15 מילים** בכל פעם.
- **קושי עולה בהדרגה**: הסשנים הראשונים מתמקדים במילים הכי חשובות/נפוצות. ככל שמתקדמים ומצליחים יותר, נפתחות מילים נוספות וקשות יותר מתוך רשימת ה-500.
- מסך הבית מציג כמה מילים ידועות לגמרי, כמה בתהליך למידה וכמה נפתחו, וכפתור 📊 פותח מפת התקדמות מלאה על כל 500 המילים.
- ההתקדמות נשמרת מקומית במכשיר (localStorage) — היא נשארת גם אם סוגרים את האפליקציה.

## עיצוב

צבעים בהירים בסגנון תכלת, כחול, צהוב וירוק — צד הספרדית בכרטיס בגוון תכלת-כחול, צד העברית בגוון ירוק-צהוב, וכפתורי הפעולה (ידעתי/טעיתי) בירוק/צהוב בהתאמה.

## מפה עיוורת 🗺️ (`/map-game/`)

אפליקציה נפרדת לגמרי מקלפי הספרדית — יש לה כתובת, manifest ו-service worker משלה, כך שאפשר להתקין ולשתף אותה בנפרד. במסך הפתיחה שלה בוחרים קטגוריה —
ערי ישראל, מדינות אירופה, מדינות ארה"ב (48 המדינות הרצופות), דרום אמריקה, אסיה או אפריקה — ואז:

- על המפה מודגש אזור אחד (עיר או מדינה), ומוצגת רשימה של עד 4 שמות לבחירה מתוכה.
- אפשר להקטין/להגדיל ולהזיז את המפה בכל קטגוריה (גלגלת עכבר, או צביטה/גרירה באצבעות בטלפון) כדי לראות בבירור גם אזורים קטנים; כפתור העיגול בפינת המפה מאפס את התצוגה חזרה לכל המפה.
- תשובה נכונה בניסיון הראשון = 10 נקודות, בניסיון השני = 4 נקודות, מניסיון שלישי ואילך = 2 נקודות.
- כל תשובה נכונה מוסיפה את השם למפה לצמיתות ומוציאה אותו מרשימת השאלות; במקומו נפתח האזור הבא בתור מתוך הרשימה, מהעיר/מדינה הגדולה והמוכרת ביותר ולאט לאט אל הקטנות והפחות מוכרות.
- ההתקדמות והניקוד לכל קטגוריה נשמרים מקומית (localStorage), בדיוק כמו התקדמות הקלפים.
- צורות המדינות/המדינות בארה"ב מבוססות על נתוני גבולות אמיתיים (ציבוריים). מפת ערי ישראל היא חלוקה גיאומטרית משוערת (Voronoi) סביב מיקום כל עיר בתוך קו המתאר החיצוני של ישראל — לא גבולות מוניציפליים רשמיים. קו המתאר החיצוני תוקן כך שיהיה שלם וללא "חריצים" פנימיים (כדי שערים כמו ירושלים יקבלו אזור תקין על המפה); זהו תיקון קרטוגרפי טכני בלבד ואין באפליקציה כל תיוג פנימי או קו גבול נוסף. קטגוריית "דרום אמריקה" כוללת רק את מדינות היבשת עצמה (לא מקסיקו, אמריקה המרכזית או הקריביים).

## מבנה הפרויקט

```
index.html               קלפי ספרדית: מסך בית, סשן לימוד, סיום סשן, מודל סטטיסטיקה
css/style.css            עיצוב קלפי הספרדית
js/words.js              מאגר 500 המילים (ספרדית-עברית, מדורגות לפי חשיבות)
js/app.js                לוגיקת הלמידה: בניית סשנים, מעקב שליטה במילה, שמירת התקדמות
manifest.json            Web App Manifest של קלפי הספרדית
service-worker.js        תמיכה במצב אופליין לקלפי הספרדית
icons/                   אייקוני קלפי הספרדית

map-game/                 אפליקציית "מפה עיוורת" - עצמאית לגמרי
map-game/index.html       מסך האפליקציה (בחירת קטגוריה, משחק, סיום קטגוריה)
map-game/css/style.css    עיצוב משחק המפה
map-game/js/mapgame-data.js  נתוני צורות הגבולות (SVG paths) לכל קטגוריה
map-game/js/mapgame.js    לוגיקת המשחק: קטגוריות, זום/פאן, ניקוד, שמירת התקדמות
map-game/manifest.json    Web App Manifest של משחק המפה
map-game/service-worker.js  תמיכה במצב אופליין למשחק המפה
map-game/icons/           אייקוני משחק המפה
```

## עטיפה כ-APK אמיתי (אופציונלי)

ה-PWA כבר מתנהג כאפליקציה מלאה במסך הבית. מי שרוצה קובץ APK/פרסום ל-Play Store
יכול לעטוף אותה בקלות עם כלים כמו [PWABuilder](https://www.pwabuilder.com/) או
Trusted Web Activity (TWA) של Google, בלי לשנות קוד — כי הקובץ `manifest.json`
כבר כולל את כל הנדרש (שם, אייקונים, צבעים, מצב standalone).
